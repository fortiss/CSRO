### Tool Development

**review_weights.py** (366 lines)
- Interactive assumption-by-assumption weight review
- Context-aware prompts with technique descriptions
- Update weights and rationales interactively
- Navigation controls (skip, quit)

**review_weights_by_category.py** (562 lines)
- Fast category-based weight assessment
- Set category defaults with exception handling
- 9 categories: IMG, RTS, NET, AUTH, SCM, HIS, MON, CIC, CRM
- Requires rationales for all weights (including 0)
- Significantly faster than assumption-by-assumption review

**generate_ontology_instances.py**
- Converts CSV data to OWL Turtle format
- Generates AssumptionWeight individuals with clean formatting
- Generates CalculationRule individuals
- Production-ready output (no development warnings)

**merge_instances_to_ontology.py**
- Merges generated instances into csro.ttl
- Replaces old partial instances with comprehensive new ones
- Maintains clean ontology structure
- Atomic file operations for safety

## Technical Details

### Weight Assessment Approach
- **Scale**: 0 (No effect) → 3 (High effect)
- **Types**: Exploitability (difficulty to exploit) and Exposure (detectability)
- **Assumptions**: 48 container security assumptions across 9 categories
- **Documentation**: Every weight includes rationale explaining the assessment

### Calculation Rules
- Link techniques to their assumption weights
- Enable dynamic risk calculation based on scenario assumptions
- Support both exploitability and exposure calculations
